Ejercicio 2: Evaluación múltiple con if / else if / else

Ingresa una puntuación y muestra en consola «Aprobaste con nota sobresaliente» si es mayor o igual a 18, «Aprobaste» si es mayor o igual a 12 o «Desaprobaste» para cualquier valor menor.

Abre la consola del navegador (F12 → pestaña «Consola») para ver el resultado.
